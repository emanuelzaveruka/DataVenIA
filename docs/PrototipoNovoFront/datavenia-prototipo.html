Como funciona

Três etapas. Nenhuma delas substitui a sua revisão — o relatório é material de apoio à pesquisa.

01

Envio da peça

PDF, DOCX ou TXT. CPF, CNPJ, endereço, telefone, e-mail e nomes não essenciais são mascarados antes de o conteúdo seguir para análise.

02

Extração das teses

O sistema identifica os pedidos, a matéria e os fundamentos, e monta a estratégia de busca no acervo do TJPR.

03

Relatório com fonte

Cada precedente vem com número do acórdão, câmara, relator, resultado e o link do inteiro teor. Sem citação que você não consiga conferir.

Antes de enviar

Como tratamos os seus dados

  • Dados pessoais identificáveis — CPF/CNPJ, endereço, telefone, e-mail, nomes de partes não essenciais — são mascarados automaticamente antes de qualquer análise.

  • O conteúdo do seu documento não é usado para treinar modelos e não é compartilhado além do necessário para gerar o relatório desta sessão.

  • Por padrão, os dados da sessão são descartados ao fechar o navegador, exceto o cache público de jurisprudência do TJPR, que não contém dados de clientes.

Resultado de apoio à pesquisa

Confirme a fonte e realize revisão jurídica independente. A classificação é triagem de pesquisa jurisprudencial — não é parecer jurídico nem previsão de êxito processual.

Limites de contraste

Medições WCAG 2.1 dos pares desta paleta. Use ao montar telas novas — três combinações exigem cuidado.

ParRazãoOnde pode usar
Branco sobre verde-500 4,0:1 Só em texto ≥14px bold — é o caso do botão primário. Não use em corpo de texto.
Branco sobre crítico 4,3:1 Só em marcador (12px bold, caixa alta). Não use em parágrafo.
Navy-400 sobre navy-800/900 3,9:1 Não use. Para texto de apoio sobre navy, use navy-300 (5,9:1) ou navy-200.
Navy-500 sobre creme 6,5:1 Texto de apoio padrão. Aprovado em qualquer tamanho.
Verde-600 sobre creme/branco 5,2:1 Links e dados numéricos. Aprovado. Verde-500 só como fundo, nunca como texto sobre claro.
Navy-800 sobre creme 14,0:1 Corpo de texto padrão.
