# HU-26 — Relatório estruturado com tendência jurisprudencial

**Épico:** J — Relatório final

**Como** advogado(a), **quero** receber um relatório com resumo do caso, questões jurídicas
analisadas, tendência jurisprudencial, pontos favoráveis, pontos contrários, riscos, distinguishing
e estratégia argumentativa sugerida, **para** ter uma base organizada para preparar minha peça.
`[§3.10, Critério de aceite 11, §12]`

**Regras de negócio**
- Tendência é expressa qualitativamente (ex.: "6 de 10 decisões sustentam a tese principal, 3
  contrárias, 1 mista"), nunca como percentual de chance de êxito. `[§3.10]`
- Proibido apresentar métricas como "83% de chance de ganhar"; usar convergência jurisprudencial
  alta/moderada/baixa/dividida. Um score numérico interno nunca é exposto como probabilidade
  jurídica. `[§3.10]`

**Validações**
- Toda seção de pontos favoráveis/contrários deve incluir: argumento, precedente, Câmara,
  relator, data, trecho e URL — nenhum desses campos pode faltar para um item exibido.

**Critérios de aceite**
- Dado um pipeline concluído com sucesso, quando o relatório é exibido, então nenhuma métrica
  percentual de "chance de ganhar" aparece na interface.
